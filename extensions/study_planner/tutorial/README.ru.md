# Study Planner: beginner guide

## Самая важная идея
- `model.orx` отвечает только за математическую постановку задачи.
- `extension.yaml` отвечает за сбор входных данных, русские подписи и показ результата.
- Python студенту для этого bundle не нужен.

## Как теперь читать bundle
1. Сначала откройте `model.orx`.
2. Найдите множество `COURSES`.
3. Затем посмотрите параметры: что известно заранее.
4. Потом найдите переменную `study_hours`.
5. Потом цель `maximize`.
6. Потом ограничения `subject to`.
7. И только после этого переходите в `extension.yaml`, чтобы понять, как эти математические символы вводятся через интерфейс.

## Что студент вводит
- список курсов;
- сколько часов нужно каждому курсу;
- сколько часов в неделю есть;
- сколько недель длится план;
- веса приоритетов для курсов.

## Что считает модель
Модель подбирает значения `study_hours[c]` так, чтобы:
- не превысить общий лимит времени;
- получить максимальную суммарную полезность.

## Что показывает приложение
Приложение показывает:
- общий доступный запас часов;
- сколько часов нужно суммарно;
- сколько часов реально распределили;
- сколько часов осталось;
- итоговую полезность;
- таблицу по каждому курсу.

## Где теперь лежит display-логика
Раньше итоговые `report` были внутри `model.orx`.
Теперь мы разделяем роли:
- `model.orx` — только оптимизационная задача;
- `extension.yaml -> display` — только то, как показать результат.

Это удобнее по двум причинам:
- математическая постановка становится чище и ближе к каноническому LP-виду;
- UI и объяснения можно менять отдельно от самой модели.

## Как переписать задачу с бумажки
Если у вас есть обычная LP-постановка из тетради или учебника, идите по шаблону:
1. выпишите множества;
2. выпишите известные параметры;
3. выпишите переменные решения;
4. запишите целевую функцию;
5. запишите ограничения;
6. только потом опишите ввод и вывод в `extension.yaml`.

## Если вы запутались
Смотрите на любую LP-задачу через три вопроса:
1. Какие есть объекты задачи?
2. Какие числа известны заранее?
3. Какие числа надо подобрать оптимально?

Если вы ответили на эти три вопроса, значит половина модели уже построена.
