# Study Planner: tutorial-версия для студентов

## Ментальная модель
- `extension.yaml` отвечает за то, **что вводит пользователь** и **что показывает приложение**.
- `model.orx` отвечает за то, **что именно считает математическая модель**.
- Python студенту не нужен: движок уже умеет читать DSL, собирать LP и решать задачу.

## Что вводит студент
1. На шаге `courses` вводится список курсов и сколько часов нужно на каждый курс.
2. На шаге `time_budget` вводится общий запас времени: часов в неделю и количество недель.
3. На шаге `priorities` вводятся веса важности курсов.

## Что считает модель
- Сначала модель вычисляет `available_hours = weekly_hours * weeks`.
- Потом она подбирает значения `study_hours[COURSES]`.
- Цель модели: сделать суммарную полезность максимальной.
- Ограничение модели: нельзя превысить общий запас времени и нельзя дать курсу больше часов, чем ему вообще нужно.

## Что показывает приложение
- Несколько числовых итогов: сколько часов доступно, сколько распределили, сколько осталось.
- Таблицу `course_plan`, где по каждому курсу видно:
  - сколько часов было нужно;
  - сколько часов реально выделили;
  - какой дефицит остался;
  - какой процент курса удалось закрыть.

## Как адаптировать этот пример под свой класс задач
1. Переименуйте `COURSES` в свое множество объектов, например `PROJECTS` или `TOPICS`.
2. В `extension.annotated.yaml` замените подписи шагов и полей на свои.
3. В `model.annotated.orx` замените параметры и переменные на свои математические обозначения.
4. Сохраните общий принцип:
   - YAML описывает ввод и вывод.
   - ORX описывает математику.
5. Проверьте bundle командой:

```bash
make extension-check EXT=study_planner
```

## На что смотреть в первую очередь
- Если вы не понимаете `extension.yaml`, начинайте сверху вниз и читайте комментарии над каждым блоком.
- Если вы не понимаете `model.orx`, читайте его в порядке: `set` -> `param` -> `var` -> `maximize` -> `st` -> `report`.
- Если кажется, что DSL сложный, смотрите на него как на три вопроса:
  - что у меня является объектами задачи;
  - какие числа я знаю заранее;
  - какие числа нужно подобрать оптимально.
