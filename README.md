# edu-operations-research-practice

Учебный репозиторий для практики по исследованию операций в образовании.

## Структура

- `00-initial-temp/` — рабочие черновики (исключены из Git)
- `.beads/` — локальная база и конфигурация beads
- `agents-issue-workflow.cncf.yaml` — workflow для issue-driven работы и коммитов

## Процесс работы

- Трекинг задач ведётся через `beads`
- Префикс issue: `eorp`
- Git-коммиты оформляются в формате workflow `agents-issue-workflow.cncf.yaml`
