# Diet / Blending example

Это канонический LP-пример: минимизация стоимости при ограничениях на покрытие потребностей.

Как читать модель:
- `FOODS` — продукты;
- `NUTRIENTS` — нутриенты;
- `buy[f]` — сколько купить продукта `f`;
- цель — минимизировать стоимость;
- ограничения `nutrition{n in NUTRIENTS}` обеспечивают покрытие каждой нормы.
