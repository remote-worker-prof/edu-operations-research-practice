1. Агент городской скорой помощи. ([LangChain Docs][1])

   * Цель: суточный план реагирования на вызовы и межбольничные перевозки.
   * Задача 1: линейное программирование для распределения резервов машин, топлива и медикаментов по подстанциям.
   * Задача 2: задача минимальной стоимости потока для перераспределения пациентов между стационарами.
   * Задача 3: задача назначения бригад и машин на вызовы.
   * Задача 4: задача маршрутизации машин скорой помощи.

2. Агент муниципального вывоза отходов. ([LangChain Docs][1])

   * Цель: суточный план вывоза, сортировки и доставки отходов на объекты переработки.
   * Задача 1: линейное программирование для определения объёмов вывоза по районам и типам отходов.
   * Задача 2: задача назначения экипажей и машин на зоны обслуживания.
   * Задача 3: job shop scheduling для расписания разгрузки и сортировки на станции.
   * Задача 4: задача маршрутизации мусоровозов.

3. Агент региональной помощи при наводнении. ([LangChain Docs][1])

   * Цель: план снабжения пунктов временного размещения и выездов спасательных групп.
   * Задача 1: линейное программирование для распределения воды, продовольствия и генераторов.
   * Задача 2: задача минимальной стоимости потока для доставки ресурсов через склады и перевалочные узлы.
   * Задача 3: задача назначения спасательных групп на заявки.
   * Задача 4: задача маршрутизации колонн и мобильных бригад.

4. Агент аэропортового наземного обслуживания. ([LangChain Docs][1])

   * Цель: суточный план обслуживания рейсов на земле.
   * Задача 1: линейное программирование для распределения топлива, автобусов, тягачей и стоянок.
   * Задача 2: задача назначения бригад и техники на рейсы.
   * Задача 3: задача расписания для окон обслуживания, заправки и погрузки.
   * Задача 4: задача маршрутизации сервисного транспорта по перрону.

5. Агент тылового обеспечения полевого госпиталя. ([LangChain Docs][1])

   * Цель: суточный план снабжения, эвакуации и распределения медресурсов.
   * Задача 1: линейное программирование для распределения коек, топлива, медикаментов и перевязочных материалов.
   * Задача 2: задача минимальной стоимости потока для эвакуации раненых и подвоза запасов.
   * Задача 3: задача назначения медицинских бригад и машин на рейсы.
   * Задача 4: задача маршрутизации санитарного транспорта.

6. Агент ремонтно-восстановительной службы базы. ([LangChain Docs][1])

   * Цель: план ремонта техники, распределения запчастей и внутренних перевозок.
   * Задача 1: линейное программирование для выбора приоритетов ремонта и распределения запчастей.
   * Задача 2: задача назначения ремонтных групп на заявки.
   * Задача 3: job shop scheduling для загрузки ремонтных боксов и мастерских.
   * Задача 4: задача маршрутизации внутренних доставок деталей и агрегатов.

7. Агент снабжения удалённых опорных пунктов. ([LangChain Docs][1])

   * Цель: суточный план подвоза воды, продовольствия, топлива и медицинских комплектов.
   * Задача 1: линейное программирование для расчёта норм снабжения по пунктам.
   * Задача 2: задача минимальной стоимости потока для распределения запасов между складами и опорными пунктами.
   * Задача 3: задача назначения экипажей и машин на рейсы снабжения.
   * Задача 4: задача маршрутизации колонн снабжения.

8. Агент гражданской обороны по эвакуации населения. ([LangChain Docs][1])

   * Цель: план эвакуации, расселения и подвоза ресурсов в безопасные зоны.
   * Задача 1: линейное программирование для распределения мест по укрытиям и пунктам размещения.
   * Задача 2: задача минимальной стоимости потока для перенаправления людских и ресурсных потоков.
   * Задача 3: задача назначения транспорта, сопровождающих и медгрупп.
   * Задача 4: задача маршрутизации эвакуационных колонн.
